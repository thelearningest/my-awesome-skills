# My Awesome Skills

A personal collection of reusable skills organized by everyday purpose.

## Categories

- `learning/` — skills for studying, teaching, and turning knowledge into experiences.
- `productivity/` — reserved for personal workflow and organization skills.
- `creative/` — skills for writing, visual, and other creative-production work.

Each skill is self-contained. Install a skill by linking its folder into `~/.codex/skills`, keeping this repository as the canonical source.

```sh
ln -s "$PWD/learning/adapt-book-to-game" "$HOME/.codex/skills/adapt-book-to-game"
```

## Included skills

- `creative/frontend-design` — build polished, production-grade frontend interfaces with a restrained, minimalist visual language.
- `learning/adapt-book-to-game` — turn a supplied fiction or nonfiction book into an original, accessible browser game through staged approval, implementation, and testing.
- `learning/exam-paper-builder` — Build mock exams and practice papers from course materials.
- `learning/lecture-slide-tutor` — Teach lecture slides one question at a time and record topics to revisit.
- `learning/playable-books` — Turn design books into interactive learning games.
- `learning/quiz-from-file` — Quiz a learner on a supplied file and track missed questions.
- `learning/slow-down-learning` — Check the learner’s starting point and teach one concept at a time.
- `learning/slow-down-understanding` — Explain a topic gradually, starting with the big picture.
- `learning/teach-step-by-step` — Teach a beginner in short lessons using reliable online sources.
- `learning/wait-what` — Rephrase a confusing explanation in plain technical English.
- `productivity/commit-major-decisions` — automatically create scoped local Git commits after approved, implemented, and verified major decisions.

## Useful, not skills

- `useful-not-skills/AGENTS.md` — reusable project instructions that ask Codex to confirm multi-step work and interview you one question at a time. Copy it into a project root to use it there.
